# use-ai-london

A one-page website for my freelance service: small AI-powered tools that make daily work easier.

Live site: https://hsk-kr.github.io/use-ai-london/

## About

I'm Seongkuk, a software engineer in London. I offer two things:

1. **I build the tool for you.**
2. **I set it up, you keep improving it.** If you already pay for ChatGPT or Claude, I set up a tool you own and show you how to change it yourself.

Right now I'm doing a few projects for free to build my portfolio. Languages: Korean (native) and English (B1–B2). Happy to meet in person in London, after work or at the weekend.

Contact: Instagram [@use.ai.london](https://instagram.com/use.ai.london)

## Tech

- A single `index.html` with inline CSS. No framework, no build step, no JavaScript.
- Mobile-first, since most visitors come from Instagram on their phone.
- Open Graph and Twitter meta tags so the link previews well when shared.
- Hosted on GitHub Pages from the `main` branch, root folder.

## Editing

Open `index.html` in a browser to preview it. Edit, commit and push to `main`; GitHub Pages redeploys automatically.
